# 잃어버린 무지개 나라 — GitHub Pages 태블릿 프로토타입 v0.7

유아가 친구를 도우며 일곱 무지개 구슬을 모으는 2D RPG입니다. 설치·빌드·API 키 없이 GitHub Pages에서 실행됩니다.

## 반영한 내용

- 주인공은 남자아이·여자아이 중 외형만 선택합니다. 직업·능력 차이는 없습니다.
- 접속하면 해든과 라온의 60초 오프닝 영상을 볼 수 있으며, 언제든 **건너뛰기**할 수 있습니다. 영상이 끝나면 캐릭터 선택으로 이어집니다.
- 중앙광장과 꽃밭·과일 정원·햇살 언덕·숲속 마을·연못·밤하늘 길·꿈의 성을 탐험합니다.
- 지도에서 장소나 친구를 터치하면 주인공이 길을 따라 걸어갑니다. PC 방향키/WASD도 사용할 수 있습니다.
- 물 주기 / 과일 담기 / 그림 조각 맞추기 / 둥지 수리 / 물길 정리 / 별등 켜기 / 오르골 열기의 7개 미션을 제공합니다.
- 그림 중심의 큰 터치 버튼, 음성 안내, 다시 듣기, 부드러운 다시 시도 안내를 제공합니다.
- 성공하면 장소의 색이 돌아오고 해당 색 구슬을 얻습니다. 이미 완료한 미션도 다시 놀 수 있지만 구슬은 중복 지급되지 않습니다.
- 구슬 7개를 모으면 광장의 나무에 하나씩 돌려놓고 친구들과 무지개 축제를 엽니다.
- 진행 기록은 저장하지 않습니다. 새로고침하거나 다시 접속하면 오프닝부터 새로운 모험을 시작합니다.
- 태블릿 **가로 화면 전용 구성**입니다. 세로로 들면 가로 회전 안내가 표시되고, 전체 화면 버튼은 브라우저가 지원하는 경우 가로 방향 잠금을 시도합니다.
- 브라우저 주소창이 보이는 가로 화면에서도 오프닝·캐릭터 선택·대화창·지도 화면의 하단 버튼이 잘리지 않도록 화면 높이에 맞춰 조정됩니다.
- 오프닝 영상은 위쪽에 비율을 유지해 온전히 표시하고, 재생·넘기기·소리 버튼은 영상과 겹치지 않는 아래쪽 조작 영역으로 분리했습니다. 영상 하단 자막도 가려지지 않습니다.
- 늘어난 지도 화면에 맞게 터치 좌표를 보정하고 친구·장소의 터치 범위를 확대했습니다. 구슬을 모두 모으기 전 중앙 나무를 눌러도 몽실 안내창이 반복되지 않습니다.
- 지도 안 오른쪽 아래의 **친구를 도와요** 버튼으로 친구 판정과 관계없이 바로 활동을 시작할 수 있습니다.

## 가장 쉬운 GitHub 업로드

별도의 계정 연결이 없어 이 파일은 GitHub에 직접 게시된 상태가 아닙니다. 아래 순서로 업로드합니다.

1. ZIP 파일을 **먼저 압축 해제**합니다.
2. GitHub에서 `rainbow-kingdom` 같은 새 저장소를 만듭니다. GitHub 무료 계정으로 Pages를 사용하는 경우 공개 저장소를 선택합니다.
3. 저장소의 **Add file → Upload files**를 누릅니다.
4. 압축을 푼 폴더 **안의 파일과 assets 폴더**를 모두 끌어 넣습니다. 폴더 자체를 통째로 한 단계 더 감싸지 마세요.
5. 저장소 첫 화면에서 `index.html`과 `assets` 폴더가 바로 보이는지 확인합니다.
6. **Commit changes**로 저장합니다.
7. **Settings → Pages → Source: Deploy from a branch → Branch: main → /(root) → Save**를 선택합니다.
8. 배포가 끝나면 같은 Pages 화면의 **Visit site**를 눌러 실행합니다. 주소는 보통 `https://사용자명.github.io/저장소명/` 형태입니다.

ZIP 파일 자체를 저장소에 올리면 게임이 실행되지 않습니다. `index.html`을 PC에서 더블클릭하는 대신 GitHub Pages 주소로 실행하세요. ES 모듈과 그림 경로를 정상적으로 읽으려면 웹 주소가 필요합니다.

공식 안내: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## 실제 플레이

1. **오프닝 보기 → 모험 시작하기 → 남자아이 또는 여자아이**를 선택합니다. 오프닝은 건너뛸 수 있습니다.
2. 후우와 몽실의 이야기를 듣고 **모험을 떠나요**를 누릅니다.
3. 지도 위의 색 구슬 그림이나 오른쪽/아래 장소 버튼으로 장소를 선택합니다.
4. 친구를 누르거나 **친구를 도와요**를 누릅니다.
5. **도와줄게!**를 누르고 미션 안내에 따라 큰 그림을 터치합니다.
6. 구슬을 얻으면 광장으로 돌아가 다른 친구를 만납니다.
7. 모두 모았으면 **무지개 나무로 가요**를 누르고 구슬 7개를 하나씩 넣습니다.

새로 시작하려면 메뉴의 **새 모험 시작하기**를 사용합니다.

## 기기별 참고

- 진행 기록은 서버나 교사 기록함에 보내지 않으며 브라우저에도 저장하지 않습니다.
- 오프닝 영상은 약 20MB로 최적화되어 있어, 인터넷 환경에 따라 최초 재생 준비 시간이 조금 걸릴 수 있습니다.
- 음성은 기기에 설치된 한국어 읽기 기능을 사용합니다. 한국어 음성이 없는 기기는 글과 그림으로 진행할 수 있습니다. API 호출이나 음성 파일 다운로드는 없습니다.
- 최초 실행은 그림을 다운로드하므로 인터넷 연결이 필요합니다. 필요한 장소 그림은 해당 장소에 갈 때 불러옵니다.
- 태블릿은 가로 방향으로 사용해 주세요. 세로로 들면 회전 안내가 표시됩니다. 방향 자동 잠금은 기기/브라우저가 허용하는 경우에만 작동합니다.

## 파일

- `index.html`: 시작·캐릭터 선택·모험 화면.
- `assets/opening.mp4`: 게임 시작 전 재생되는 오프닝 영상.
- `styles.css`: 태블릿·모바일·PC 화면 구성.
- `game.mjs`: 화면 전환, 대화, 터치 활동, 저장, 음성.
- `core.mjs`: 미션 상태, 구슬과 엔딩 상태, 길 찾기.
- `renderer.mjs`: 실제 그림과 캐릭터 동작 표시.
- `asset-data.mjs`: 시트에서 그림을 읽는 좌표.
- `assets/`: 이번 프로젝트의 실제 이미지 21장.
- `.nojekyll`: 정적 파일을 그대로 제공하기 위한 설정.
- `tests/`: 핵심 동작 테스트.

## 검증과 남은 확인

핵심 테스트: 7개 미션과 전체 엔딩, 중복 입력, 잘못된 선택, 저장 복구, 모든 장소 이동, 낮은 프레임 속도에서 도착, 이미지 파일·좌표 범위 확인. 앱의 실제 그리기 코드로 장소별 화면과 캐릭터 합성도 확인했습니다.

현재 작업 환경에서 실제 브라우저를 조작하는 검증 도구가 제공되지 않아 브라우저에서 오프닝 영상·전체 화면·음성·터치 이벤트를 끝까지 실행한 테스트는 수행하지 못했습니다. GitHub Pages에 올린 후 사용하실 태블릿에서 **오프닝 보기 → 건너뛰기 → 모험 시작하기 → 첫 미션** 순서로 먼저 확인해 주세요. 캐릭터는 생성된 포즈 시트를 사용하며 프레임 사이에 약간의 그림 차이가 남아 있는 프로토타입입니다.

개발자가 Node.js를 사용할 경우 `node --test tests/game.test.mjs`로 핵심 테스트를 실행할 수 있습니다. 앱 실행을 위해 Node.js나 npm 설치가 필요한 것은 아닙니다.
